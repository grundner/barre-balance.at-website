# Glossar

Begriffe, wie sie in diesem Projekt verwendet werden. Die Dokumentation
verwendet – wie das Ausgangsbriefing – für Kundinnen und Teilnehmerinnen
überwiegend die weibliche Form.

## Marke & Angebot

| Begriff | Bedeutung |
|---|---|
| **Movement Brand** | Die persönliche Marke von Isabell Grundner. Umfasst mehrere Bewegungsformen und ist bewusst größer als ein einzelnes Kursformat. |
| **Barre & Balance** | Name der Marke. Domain `barre-balance.at`. |
| **Format / Methode** | Eine Bewegungsform innerhalb der Marke, z. B. Barre, Pilates, Modern Jazz / Dance. Weitere Formate können hinzukommen. |
| **Kurs** | Ein angebotenes Format mit Beschreibung, Zielgruppe, Intensität, Dauer, Ort, Trainerin und Terminen. |
| **Termin** | Ein konkreter Zeitpunkt, zu dem ein Kurs stattfindet und gebucht werden kann. |
| **Serienkurs** | Ein Kurs mit wiederkehrenden Terminen, den Isabell im Betreiberbereich anlegt. |
| **Specials / Workshops** | Sonderformate neben den regulären Kursen. Ausgestaltung offen. |
| **Stundenplan** | Übersicht der buchbaren Termine. |
| **Gutschein** | Perspektivisches Angebot (Kandidat); Ausgestaltung offen. |

## Personen & Rollen

| Begriff | Bedeutung |
|---|---|
| **Isabell** | Inhaberin, Trainerin und Betreiberin der Plattform. |
| **Trainerin** | Leitet einen Kurs. Aktuell ausschließlich Isabell; eine Öffnung für weitere Trainerinnen ist offen. |
| **Interessentin** | Person, die das Angebot kennenlernt, aber noch nicht gebucht hat. |
| **Teilnehmerin** | Person, die an Kursen teilnimmt bzw. einen Termin gebucht hat. |
| **Kundin** | Person, die Isabells Angebot nutzt. Registrierte Kundinnen haben einen persönlichen Bereich im Kundenbereich. |
| **Digitale Kundin** | Kundin, die digitale Trainingsangebote nutzt (spätere Ausbaustufe). |

## Plattform

| Begriff | Bedeutung |
|---|---|
| **Öffentliche Website** | Emotionaler, markenorientierter Bereich ohne Login. |
| **Kundenbereich / App / Kundenportal** | Eingeloggter, funktionaler und personalisierter Bereich für Kundinnen. |
| **Betreiberbereich** | Administrativer Bereich für Isabell. |
| **Buchung** | Reservierung eines Platzes für einen Termin. |
| **Anfrage** | Kontaktaufnahme einer Interessentin zu einem Kurs oder Termin über E-Mail, Telefon oder WhatsApp. Ersetzt in der Website-Phase die Buchung. |
| **Stornierung** | Rücknahme einer Buchung. Regeln offen. |
| **Warteliste** | Vormerkung für einen vollen Termin; bei frei werdendem Platz wird benachrichtigt. Regeln offen. |
| **Session** | Eine digitale Trainingseinheit (On-Demand), z. B. Mobility, Barre, Pilates. |
| **Programm / Serie** | Zusammenhängende Folge digitaler Sessions. |
| **Challenge** | Trainingsangebot im Kundenbereich bzw. digitalen Angebot (spätere Ausbaustufe). Ausgestaltung offen. |
| **Check-in** | Kurze Rückmeldung nach einer Einheit (Befinden, Anstrengung, beanspruchte Bereiche, Energielevel). |
| **Blog-Beitrag** | Redaktioneller Artikel auf der Website; kann als Entwurf (`draft`) geführt werden. |
| **Stundenplan-Hinweis** | Zeitlich begrenzte Information zum Stundenplan, z. B. eine Pause, mit explizitem Zeitraum. |
| **Design System** | Das Claude Design System „Barre & Balance“: Quelle für Tokens, Komponenten und visuelle Regeln. |
| **Platzhalter** | Inhalt, der noch nicht von Isabell bestätigt ist und vor dem Launch ersetzt werden muss. |
| **Movement OS** | Langfristige Vision einer Plattform, die Kurse, Community, Buchungen, Content, Kommunikation, Personalisierung und Business Administration verbindet. |
