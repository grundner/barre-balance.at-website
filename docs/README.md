# Projektdokumentation – Index

Diese Dokumentation ist die maßgebliche, versionierte Quelle des Projektwissens
für die Website und digitale Plattform des Movement-Business von
**Isabell Grundner**.

Arbeitsweise und Autoritätsregeln: siehe [`CLAUDE.md`](../CLAUDE.md).

## Herkunft

Der initiale Inhalt stammt aus dem Briefing `barre-balance.at.md`
(ursprünglich als Ausgangsbasis für Claude Design verfasst). Das Briefing wurde
am 2026-09-12 in die folgenden Dokumente überführt und anschließend entfernt.

## Statuskennzeichnung

Inhalte tragen einen Status, damit Ideen nicht versehentlich als Anforderungen
umgesetzt werden.

| Status        | Bedeutung                                                                 |
|---------------|---------------------------------------------------------------------------|
| **Akzeptiert** | Verbindlich. Darf Design und Umsetzung steuern.                          |
| **Vorschlag**  | Gewünschte Richtung, aber noch nicht final abgestimmt.                   |
| **Hypothese**  | Arbeitsannahme, die validiert werden muss.                               |
| **Kandidat**   | Mögliche Funktion oder Idee. Nicht zur Umsetzung freigegeben.            |
| **Offen**      | Bewusst nicht entschieden. Siehe [Offene Fragen](open-questions.md).     |

Ohne explizite Kennzeichnung gilt der im Dokumentkopf angegebene Status.
